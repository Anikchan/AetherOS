## Grading rules (implemented and tested)

| Observation | Tier |
|---|---|
| no checks | `Untested` (gate stays closed) |
| failed `install` / `launch` / `window` / `stability` | `D` |
| all supplied checks pass, no tweak | `A` |
| documented tweak needed, no gate failure | `B` |
| a non-gate check failed, no documented tweak | `C` |

Score = passed check weight / 120 (install, launch, window, stability = 20;
input, video = 10; audio, files, network, persistence = 5). A missing check
scores 0, so a partial run cannot inflate the tier.
